## 一、项目概述

### 1.1 项目背景

北京2026年高考志愿填报改革背景下，考生需要在知道分数后快速完成志愿选择。传统方式依赖 Excel 表格和经验判断，效率低且容易出错。本系统提供数字化、智能化的高考志愿辅助决策工具。

### 1.2 核心价值

- **数据整合**：聚合2022-2025年北京高考录取数据
- **智能推荐**：基于位次算法的冲-稳-保推荐
- **模拟填报**：可视化志愿表管理
- **科学决策**：用数据替代感觉

### 1.3 目标用户

- 北京2026年高考考生
- 考生家长（辅助决策）
- 高中班主任（批量指导）

### 3.2 数据架构

```
数据源
├── GitHub: scottli139/beijing-gaokao-scores（录取数据）
├── GitHub: scottli139/beijing-gaokao-score-segments（一分一段）
└── 北京教育考试院（官方权威数据）

数据模型
├── University（院校）
│   ├── code: 院校代码
│   ├── name: 院校名称
│   └── level: 985/211/一本/二本
│
├── MajorGroup（专业组）
│   ├── code: 专业组代码
│   ├── university: 所属院校
│   ├── year: 年份
│   ├── batch: 录取批次
│   ├── minScore: 最低录取分数
│   ├── minRank: 最低录取位次
│   ├── selectionReq: 选科要求
│   └── planCount: 招生计划人数
│
└── ScoreSegment（一分一段）
    ├── year: 年份
    ├── score: 分数
    ├── count: 本段人数
    └── cumulative: 累计人数
```

### 3.3 推荐算法设计

```
输入：考生分数 + 选科组合
输出：冲/稳/保三档推荐

Step 1: 分数 → 位次
  getRank(score, year) → cumulative_rank

Step 2: 筛选符合选科的院校
  filter(majorGroups, subjects) → filteredGroups

Step 3: 位次差计算
  rank_diff = student_rank - school_rank

  ├─ 冲：rank_diff ∈ [0, school_rank × 0.08]  （位次在院校录取位次108%以内）
  ├─ 稳：rank_diff ∈ [-school_rank×0.07, 0]   （位次在院校录取位次93%~100%）
  └─ 保：rank_diff < -school_rank × 0.07       （位次明显优于院校录取位次）

Step 4: 排序输出
  冲：按 rank_diff 升序（差值越小越稳）
  稳：按 rank_diff 降序（差值越大越稳）
  保：按 rank_diff 降序
```

## 六、接口设计（未来后端）

### 6.1 REST API

```
GET  /api/v1/schools?year=2025&batch=本科批&page=1&limit=50
     → 返回院校列表（分页）

GET  /api/v1/schools/:code?year=2025
     → 返回院校详情（含所有专业组）

GET  /api/v1/recommend?score=650&subjects=物理,化学&year=2025
     → 返回推荐结果

GET  /api/v1/score-segments?year=2025
     → 返回一分一段表

GET  /api/v1/similar-scores?score=650&year=2025
     → 返回同分去向

POST /api/v1/plans
     → 创建志愿方案

GET  /api/v1/plans?user_id=xxx
     → 获取用户所有方案
```

### 6.2 数据更新机制

- 每年高考出分后（6月23日左右），从北京教育考试院导出数据
- 人工整理成标准 CSV 格式
- 触发 GitHub Actions 自动导入到数据库
- 前端通过 CDN 刷新缓存
