# 北京2026高考志愿填报系统

智能推荐 + 往年数据查询 + 模拟填报

**访问地址**: https://gk.5176nas.site

---

## 功能

- **📊 往年数据查询** — 2023-2025年北京高考本科批次录取数据
- **🎯 智能推荐（冲-稳-保）** — 输入高考成绩和选科，自动推荐可冲刺/稳妥/保底院校
- **📋 志愿表管理** — 添加收藏，生成最终志愿填报列表
- **📖 政策指南** — 平行志愿规则解读

---

## 数据来源

| 年份 | 记录数 | 来源 |
|------|--------|------|
| 2023 | ~1300条 | [scottli139/beijing-gaokao-scores](https://github.com/scottli139/beijing-gaokao-scores) |
| 2024 | ~1258条 | 同上 |
| 2025 | ~1391条 | 同上 |

共覆盖 **600+ 所院校**，包括：
- 985/211高校（北京大学、清华大学、人大、北航、北理工等）
- 市属重点高校（首都医科大、首都师范、北京工业等）
- 二本院校（北方工业、北京信息工程、北京印刷学院等）

## 技术栈

- 纯前端 HTML/CSS/JavaScript（无需构建）
- nginx 静态文件托管（腾讯云新加坡节点）
- Let's Encrypt HTTPS 证书

## 更新数据

如需更新数据，修改 `src/app.js` 中的 `historicalData` 对象：

```javascript
const historicalData = {
  "2025": [ /* 专业组记录 */ ],
  "2024": [ /* 专业组记录 */ ],
  "2023": [ /* 专业组记录 */ ]
};
```

每条记录格式：
```json
{
  "school": "学校名称",
  "code": "院校代码",
  "group": "专业组编号",
  "batch": "提前批/本科批",
  "level": "985/211/一本/二本",
  "minScore": 最低录取分数,
  "selection_req": "物理＋化学/不限等",
  "subjects": ["物理", "化学"],
  "remark": "附加说明"
}
```
